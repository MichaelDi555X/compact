# Cross-Chain Interoperability with Base

Base participates in the Superchain, facilitating standardized cross-chain communication.

## Messaging

OP Stack provides L2-to-L2 and L1-to-L2 messaging protocols. Applications can send messages that are relayed and executed on destination chains after appropriate finality.

## Ecosystem Tools

Bridges, aggregators, and messaging protocols extend Base's reach to other L2s and L1. Careful handling of message nonces, gas limits for execution, and security assumptions is required for reliable cross-chain functionality.
