# Security Audits for Base Projects

Independent security audits are strongly recommended for any non-trivial smart contracts deployed on Base.

## Process

- Engage reputable audit firms familiar with OP Stack and L2 specifics.
- Provide comprehensive documentation, test suites, and threat models.
- Address findings thoroughly and consider follow-up reviews for significant changes.

Public disclosure of audit reports builds trust. Bug bounty programs can complement formal audits for ongoing security.
