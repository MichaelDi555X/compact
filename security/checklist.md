# Public Web3 security checklist

This checklist is for educational projects and public repositories.

- [ ] No private keys, seed phrases, API secrets, or credentials are committed.
- [ ] Network and chain ID are explicit.
- [ ] External contract addresses are documented and verified.
- [ ] User-controlled input is validated.
- [ ] State-changing functions have clear access-control rules.
- [ ] Events describe important state changes.
- [ ] Tests cover normal and failure paths.
- [ ] Dependencies are pinned or reviewed.
- [ ] Deployment artifacts are reproducible where practical.
- [ ] A testnet deployment is completed before mainnet use.
