# Fault Proofs on Base

Base is progressing toward a fully permissionless fault proof system as part of the OP Stack roadmap.

## Current Status

Optimistic rollups rely on a challenge period during which invalid state transitions can be disputed. The introduction of interactive fault proofs enhances security by allowing broader participation in validation.

## Importance

Robust fault proofs reduce reliance on centralized parties for security and align with Ethereum's decentralized ethos. Developers and users should monitor Base announcements regarding proof system upgrades and challenge windows.
