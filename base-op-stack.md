# Base and the OP Stack

Base is built on the OP Stack, an open-source framework for optimistic rollups maintained by the Optimism Collective and adapted by Coinbase.

## Implications for developers

- Shared security assumptions with other OP Stack chains.
- Compatible tooling for deployment, monitoring, and fault proofs.
- Follow OP Stack upgrade processes for protocol-level changes.
- Review Base-specific configurations and differences from vanilla Optimism.
