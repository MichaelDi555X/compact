# Base Ethereum Research & Builder Toolkit

A practical, open-source workspace for exploring Ethereum on Base, with an emphasis on simple, auditable tooling and developer education.

## Scope
- Base and Ethereum network fundamentals
- Wallet and transaction safety
- Smart-contract design notes
- Developer utilities and examples
- Mobile-friendly Web3 development workflows

## Networks
- Base Mainnet: chain ID 8453
- Base Sepolia: chain ID 84532

This repository is educational and avoids custody of user funds or private keys.

## Public project map
- `docs/` — network and development notes
- `examples/` — small, reusable Web3 examples
- `contracts/` — educational Solidity contracts
- `scripts/` — safe developer utilities
- `security/` — threat-model and safety notes

## Confidentiality boundary
This public repository contains only general-purpose Base/Ethereum material. Proprietary projects and unpublished inventions are intentionally kept outside this repository.
