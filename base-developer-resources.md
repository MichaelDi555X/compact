# Developer Resources for Base

Building on Base is supported by comprehensive official documentation and community tools.

## Official Resources

- Base documentation portal covering network details, RPCs, and deployment guides.
- Faucets for Base Sepolia testnet tokens.
- Block explorers such as Basescan for transaction inspection and contract verification.

## Recommended Tooling

Hardhat and Foundry configurations for Base, viem and ethers.js providers, and wallet connection libraries like wagmi and RainbowKit are widely used. Continuous monitoring of Base status pages ensures reliability during development.
