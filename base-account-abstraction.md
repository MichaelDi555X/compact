# Account Abstraction on Base

Base supports ERC-4337 account abstraction, enabling smart contract wallets with advanced features.

## Benefits

- Gas sponsorship (paymasters) for improved user experience.
- Session keys and social recovery mechanisms.
- Batch transactions and programmable validation logic.

## Implementation Notes

Developers integrate with EntryPoint contracts deployed on Base. Popular libraries and infrastructure providers facilitate AA adoption. Testing on Base Sepolia is recommended before mainnet deployment.
